# Netflix Content Analytics Dashboard | Power BI

A comprehensive Power BI dashboard built to analyze Netflix's global content library. This project transforms raw Netflix data into interactive business insights using Power Query, DAX, and Power BI visualizations.

---

## Project Overview

The objective of this project is to analyze Netflix's content catalog and uncover trends related to content type, genres, countries, ratings, release years, and platform growth.

The dashboard enables users to explore Netflix's content through interactive filters and visualizations, supporting data-driven decision-making.

---

## Objectives

- Analyze Netflix's content distribution.
- Compare Movies vs TV Shows.
- Identify top content-producing countries.
- Discover popular genres and content ratings.
- Analyze yearly additions and release trends.
- Build an interactive dashboard using Power BI.

---
